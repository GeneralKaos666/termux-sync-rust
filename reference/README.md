# Python reference

This is the original Python implementation of termux-sync, kept for behavior reference.
The shipped application is the Rust code in `../rust/app`; nothing here is built, tested
or installed by the root scripts. Its workflows are parked under
`reference/.github/workflows/` and are not active.

Run it only for comparison:

```bash
cd reference
python3 termux-sync.py help
```
